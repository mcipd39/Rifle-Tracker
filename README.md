# Precision Reload Tracker v4

Upload the entire contents of this folder to the root of the GitHub Pages repository.

## Included
- Installable iPhone Home Screen PWA
- Offline operation after first load
- Existing `precisionReloadTracker` local data compatibility
- Smart reusable dropdown/autocomplete values
- Firearm and barrel hierarchy
- Barrel-specific and bullet-specific lands history by barrel round count
- Current jump calculation using the latest matching lands measurement
- Shooting logs with raw velocity strings and automatic average, sample SD and ES
- Ladder / multi-load testing
- Load recipes, recipe duplication and quick logging
- Brass lots and firing counts
- Component inventory and reorder alerts
- Barrel round counts and cleaning reminders
- Maintenance history
- Backup and restore
- Most fields are optional

## Upgrade
Export a backup from the current app before uploading. Keep the same GitHub Pages URL so the browser can continue using the existing local data.
